# Selected results

This directory contains selected figures and compact summary values needed
to inspect the released analyses. Full derived inputs remain under `data/`,
while all intermediate outputs generated by the reproduction command are
written to the ignored `reproduced/` directory.

- `figures/fig1a_design.pdf` and `.png`: paired-generation pipeline.
- `figures/fig1b_conditions.pdf` and `.png`: four chord conditions on the
  shared scoring grid.
- `figures/fig2_paired.pdf` and `.png`: local probe versus complete replay.
- `figures/fig3_calibration.pdf` and `.png`: calibration gains across
  recognizers and chroma representations.
- `figures/fig4_ablation.pdf` and `.png`: temporal, relational and joint
  matching ablation.
- `metrics_summary.json`: MUSDB18-HQ summary values.
- `moisesdb.json`: recomputed pilot, validation, recognizer, ablation and symbolic-interface statistics.
