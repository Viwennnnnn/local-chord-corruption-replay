# Selected results

This directory contains selected figures and compact summary values needed
to inspect the released analyses. Full derived inputs remain under `data/`,
while all intermediate outputs generated by the reproduction command are
written to the ignored `reproduced/` directory.

- `figures/fig1_calibrated_protocol.pdf` and `.png`: main paired comparison and
  calibration result.
- `figures/fig2_relation_seed.pdf` and `.png`: relation-control and profile
  construction result.
- `metrics_summary.json`: MUSDB18-HQ summary values.
- `moisesdb.json`: recomputed pilot, validation, recognizer, ablation and symbolic-interface statistics.
- `figures/chord_conditions.png`: overview of the paired chord conditions.
